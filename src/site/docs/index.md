# 量潮媒体中心 — 设计

## 定位

媒体中心（qtmedia）：统一展示量潮在各媒体平台的账号矩阵与内容动态。

设计输入：`data/journal/`（运营日志）、`data/archive/`（内容归档）、`data/profile/`（运营档案）。

核心问题只有一个：**量潮的媒体矩阵在哪、在说什么、怎么找到我们？**

## 首页

### Hero

一句话说明媒体中心是什么，附平台锚点。

> 量潮媒体中心。
> 统一入口：量潮在各大媒体平台的账号矩阵与内容动态。

### 媒体矩阵

首页核心区块。展示各平台账号条目：平台 + 账号名 + 定位说明 + 链接，附"访问 →"。

### 内容动态

按时间倒序展示近期内容（文章 / 视频 / 动态），每条含类型标签、标题、日期与原文链接。

### 联系

GitHub / 邮件 / 其他社交链接。

## 风格约束

- 克制 / 文字优先 / 留白
- 颜色仅黑、白、灰；无动画、无渐变、无卡片阴影
